# Claude Code Skills

A collection of custom skills for Claude Code.

## Available Skills

### check-weather

Check current weather conditions and forecasts for any location using web search.

**Usage:**
- Ask naturally: "What's the weather in Tokyo?"
- Or invoke directly: `/check-weather`

**Features:**
- Current temperature (Celsius and Fahrenheit)
- Weather conditions
- Humidity and wind
- Forecasts

## Installation

Copy the `.claude/skills/` folder to your project or to `~/.claude/skills/` for personal use across all projects.
